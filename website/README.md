# Korynth Labs · Dashboard

Next.js 15 + React 19 + Tailwind CSS 4 dashboard for Korynth Labs.

## Running

```bash
cd website
npm install
npm run dev
```

Open http://localhost:3000.

## Architecture

- **App Router** (Next.js 15) — all pages in `app/`.
- **Single source of truth**: `../.firm/state.json` — read server-side, fresh per request.
- **SSE** at `/api/events` for live updates.
- **No DB** — file-system only. State.json is regenerated by `/firma` at every Core Loop step 12.

## Pages

| Path              | Purpose |
|-------------------|---------|
| `/`               | Landing page (public if visibility=public) |
| `/dashboard`      | Live operational dashboard |
| `/email`          | Email client (central principal-firm comms) |
| `/team`           | Dynamic org chart from `.firm/employees/_roster.yaml` |

| `/compliance`     | DSGVO + EU AI Act + AI Ethics |
| `/customer`       | Principal profile, success plan, NPS |
| `/acquisition`    | 8 channels offered as a service to principal |
| `/knowledge`      | Knowledge graph explorer + decay log |
| `/cases`          | Case studies (public, sanitized) |
| `/transparency`   | AI ethics statement, audits, B-Corp (public) |

## API routes

- `GET  /api/state` — current state.json
- `GET  /api/events` — SSE stream of state changes
- `POST /api/email/send` — write inbound email to filesystem
- `PUT  /api/email/mark-read` — flip frontmatter status
- `GET  /api/email/thread` — thread aggregation
- `POST /api/ki-decision` — human-in-loop approval endpoint
