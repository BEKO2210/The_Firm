# Emergency Procedures

## Overview

Crisis response: data breach, security incident, system outage, principal escalation.

## Key points

- Data breach: trigger 72h DSGVO notification clock.
- Security incident: SRE leads, Critic facilitates blameless postmortem.
- Outage: SRE on-call, communications via `continuity/crisis-communication-templates/`.
- Principal escalation: CEO leads, all hands on deck.
