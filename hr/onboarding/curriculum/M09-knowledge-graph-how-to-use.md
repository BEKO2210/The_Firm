# Knowledge Graph

## Overview

Structured knowledge store with auto-decay. Concepts, decisions, learnings, patterns, people.

## Key points

- Auto-decay: nodes flagged at 180 sim-days without revalidation; deleted at 365.
- Public subset published quarterly (PII scrubbed).
- Auto-created from spec docs, ADRs, postmortems, retros, peer-review comments.
